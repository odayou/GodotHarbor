# 插件管理

## 导入插件

### 从本地目录导入

1. 点击 **导入插件** → **本地目录**
2. 选择包含 `plugin.cfg` 的插件目录
3. 选择导入模式：
   - **复制到仓库**（推荐）— 将插件复制到仓库，原目录不受影响
   - **纳入管理** — 移动到仓库并创建符号链接回原位置
   - **仅记录索引** — 不移动文件，只记录插件信息

### 从 Git 仓库导入

1. 点击 **导入插件** → **Git 仓库**
2. 输入仓库 URL（如 `https://github.com/user/plugin.git`）
3. 应用自动克隆仓库并识别插件

### 从项目扫描导入

1. 点击 **导入插件** → **项目扫描**
2. 应用扫描所有项目的 `addons` 目录
3. 列出发现的插件，选择要导入的

### 从 Asset Library 导入

1. 点击 **导入插件** → **Asset Library**
2. 搜索或浏览 Godot 官方资产库
3. 选择插件后点击导入

## 编辑精选

当插件仓库为空时，页面底部展示"编辑精选"区域，推荐社区优质 Godot 插件：

- 精选列表随应用内置，无需网络即可查看
- 点击精选插件自动填入 Git 导入对话框的 URL
- 可关闭精选推荐区域

当前精选包含：GodotSteam、Dialogic、PhantomCamera、GUT、LimboAI、Aseprite Wizard、Terrain3D、Godot SQLite、Pixelizer、GodotTIE

## 重复检测

导入时如果仓库中已存在同名插件，会提示：

- **仍然导入** — 作为新版本添加
- **替换现有版本** — 覆盖已有版本
- **取消** — 放弃导入

## 版本管理

每个插件可以有多个版本，每个版本包含一个或多个单元（Unit）。

- **切换版本** — 在插件详情页选择不同版本
- **删除版本** — 删除不需要的版本
- **更新版本** — 从 Git 拉取最新代码

### 单元（Unit）

单元是版本内的子目录级别的可挂载组件。例如一个插件可能包含：
- 主模块单元
- 示例单元
- 文档单元

绑定到项目时可以选择挂载哪些单元。

## 插件更新

### 检查更新

- 单个插件：右键 → **检查更新**
- 全部插件：点击 **检查更新** 按钮

### 更新流程

1. 检测到有新版本的插件
2. 点击 **更新** 拉取最新代码
3. 已绑定的项目自动使用新版本

## 收藏

点击插件卡片上的 ⭐ 图标可将插件标记为收藏，收藏的插件在列表中优先显示。

## 存储管理

在插件页面底部可以查看存储统计：

- 插件数量、版本数量、绑定数量
- 占用空间
- 孤立文件（未被任何版本引用的文件）
- 重复内容（相同文件哈希的文件）

点击 **清理孤立文件** 可释放磁盘空间。

## 团队配置

### 导出团队配置

1. 在插件页面点击 **团队配置** → **导出**
2. 选择要包含的项目和绑定关系
3. 生成 JSON 配置文件

### 导入团队配置

1. 点击 **团队配置** → **导入**
2. 选择配置文件
3. 应用自动创建绑定关系

团队配置适合多人协作时同步插件版本和绑定关系。
