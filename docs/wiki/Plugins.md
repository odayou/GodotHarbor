# 插件管理

## 资产类型

GodotHarbor 支持管理三种类型的资产：

| 类型 | 说明 | 标识 | 挂载路径 |
|------|------|------|---------|
| **插件** (Plugin) | 包含 `plugin.cfg` 的标准 Godot 编辑器插件 | 默认类型 | `addons/<name>` |
| **资产包** (AssetPack) | 不含 `plugin.cfg` 的资源集合（shader、材质、脚本库等） | 卡片标签 | `assets/<name>` |
| **项目模板** (Project) | 包含 `project.godot` 的完整项目（模板、演示） | 卡片标签 | 不挂载，作为新项目导入 |

> 导入时系统自动检测资产类型，无需手动选择。

## 导入插件

### 从本地目录导入

1. 点击 **导入插件** → **本地目录**
2. 选择插件目录（含 `plugin.cfg` 的标准插件，或不含的资产包均可）
3. 选择导入模式：
   - **复制到仓库**（推荐）— 将插件复制到仓库，原目录不受影响
   - **纳入管理** — 移动到仓库并创建符号链接回原位置
   - **仅记录索引** — 不移动文件，只记录插件信息

### 从 Git 仓库导入

1. 点击 **导入插件** → **Git 仓库**
2. 输入仓库 URL（如 `https://github.com/user/plugin.git`）
3. 应用自动克隆仓库并识别插件

### 从项目扫描导入

1. 点击 **导入插件** → **项目扫描**
2. 应用扫描所有项目的 `addons` 目录
3. 列出发现的插件，选择要导入的
4. 所有导入模式均自动为源项目创建绑定关系

> 扫描结果保留每个项目的插件信息，不会因同名插件而丢失项目关联。导入时基于内容哈希去重：内容相同的插件只保留一份，但会为每个源项目创建绑定。

### 从 Asset Library 导入

1. 点击 **导入插件** → **Asset Library**
2. 搜索或浏览 Godot 官方资产库
3. 选择资产后点击导入
4. 系统自动检测资产类型：
   - 含 `plugin.cfg` → 作为插件导入，可绑定到项目
   - 不含 `plugin.cfg` → 作为资产包导入，可绑定到项目
   - 含 `project.godot` → 作为项目模板导入，注册为新项目

## 编辑精选

当插件仓库为空时，页面底部展示"编辑精选"区域，推荐社区优质 Godot 插件：

- 精选列表随应用内置，无需网络即可查看
- 点击精选插件自动填入 Git 导入对话框的 URL
- 可关闭精选推荐区域

当前精选包含：GodotSteam、Dialogic、PhantomCamera、GUT、LimboAI、Aseprite Wizard、Terrain3D、Godot SQLite、Pixelizer、GodotTIE

## 重复检测

导入时如果仓库中已存在相同内容的插件（基于内容哈希），会提示：

- **仍然导入** — 作为新插件添加
- **替换现有版本** — 覆盖已有插件
- **取消** — 放弃导入

> 如果内容哈希相同但来自不同项目，系统会自动复用已有插件并为源项目创建绑定，无需重复导入。

## 版本管理

每个插件可以有多个版本，每个版本包含一个或多个单元（Unit）。

- **切换版本** — 在插件详情页选择不同版本
- **删除版本** — 删除不需要的版本
- **更新版本** — 从 Git 拉取最新代码

### 单元（Unit）

单元是版本内的子目录级别的可挂载组件。例如一个插件可能包含：
- 主模块单元
- 示例单元
- 文档单元

绑定到项目时可以选择挂载哪些单元。

**虚拟单元**：对于不含 `plugin.cfg` 的资产包，系统会创建虚拟单元，使用 Asset Library 或导入时的元数据作为名称和版本信息。虚拟单元在绑定和挂载时与普通单元行为一致。

## 插件更新

### 检查更新

- 单个插件：右键 → **检查更新**
- 全部插件：点击 **检查更新** 按钮

### 更新流程

1. 检测到有新版本的插件
2. 点击 **更新** 拉取最新代码
3. 已绑定的项目自动使用新版本

## 收藏

点击插件卡片上的 ⭐ 图标可将插件标记为收藏，收藏的插件在列表中优先显示。

## 存储管理

在插件页面底部可以查看存储统计：

- 插件数量、版本数量、绑定数量
- 占用空间
- 孤立文件（未被任何版本引用的文件）
- 重复内容（相同文件哈希的文件）

点击 **清理孤立文件** 可释放磁盘空间。

## 团队配置

### 导出团队配置

1. 在插件页面点击 **团队配置** → **导出**
2. 选择要包含的项目和绑定关系
3. 生成 JSON 配置文件

### 导入团队配置

1. 点击 **团队配置** → **导入**
2. 选择配置文件
3. 应用自动创建绑定关系

团队配置适合多人协作时同步插件版本和绑定关系。
