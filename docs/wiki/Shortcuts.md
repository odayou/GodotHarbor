# 快捷键

## 全局快捷键

| 快捷键 | 功能 | 说明 |
|---|---|---|
| `Ctrl+K` | 打开命令面板 | 搜索项目、插件、引擎、设置等 |
| `Ctrl+B` | 折叠/展开侧边栏 | 切换侧边栏显示状态 |
| `Ctrl+T` | 循环切换主题 | 在浅色→深色→系统→火山之间切换 |
| `Ctrl+D` | 深色/浅色切换 | 快速切换深色和浅色模式 |

> macOS 用户使用 `Cmd` 键代替 `Ctrl` 键。

## 命令面板

打开命令面板（`Ctrl+K`）后：

| 按键 | 功能 |
|---|---|
| `↑` / `↓` | 上下移动选择 |
| `Enter` | 执行选中项 |
| `Esc` | 关闭命令面板 |

命令面板支持搜索以下内容：

- **命令** — 扫描项目、导入插件、发现引擎等
- **项目** — 快速跳转到项目
- **插件** — 快速跳转到插件
- **引擎** — 快速跳转到引擎
- **设置** — 快速打开设置页面

## 对话框通用快捷键

| 按键 | 功能 |
|---|---|
| `Esc` | 关闭当前对话框 |
| `Enter` | 确认操作（在输入框中） |
