# 设置

设置页面分为以下区域：

## 扫描

### 扫描目录

管理项目扫描的搜索路径：

- **添加目录** — 选择要扫描的文件夹
- **移除目录** — 删除不需要的扫描路径

应用会在这些目录中递归查找 Godot 项目（包含 `project.godot` 文件的目录）。

### 自动扫描

- **启动时自动扫描** — 每次启动应用时自动扫描项目
- **启动时自动发现引擎** — 每次启动时自动查找已安装的引擎

## 挂载策略

选择插件绑定到项目时使用的挂载方式：

| 策略 | 说明 | 适用场景 |
|---|---|---|
| **Symlink** | 创建符号链接（推荐） | 通用，支持实时同步 |
| **Junction** | 创建 NTFS Junction | Windows 专用，兼容性更好 |
| **Copy** | 复制文件 | 不支持链接的环境 |

- **Symlink**：插件仓库和项目之间建立符号链接，修改即时同步
- **Junction**：Windows 上 Symlink 的替代方案，不需要管理员权限
- **Copy**：将插件文件复制到项目目录，不建立链接关系

## 插件仓库

### 存储路径

设置插件仓库的存储位置。默认位于应用数据目录下。

更改存储路径时，可以选择：
- **迁移数据** — 将现有插件文件移动到新路径
- **跳过迁移** — 仅更改配置，不移动文件

### 自动更新检查

- **自动检查插件更新**
- **自动检查应用更新**
- **自动检查引擎更新**
- **检查间隔**（1-168 小时）

## 引擎镜像

管理引擎下载的镜像源：

- **官方源** — Godot 官方 GitHub Releases（不可删除）
- **自定义源** — 添加第三方镜像加速下载

### 添加镜像

1. 点击 **+ 添加镜像**
2. 输入镜像名称和 Base URL
3. 选择是否启用
4. 保存设置后生效

### 编辑/删除镜像

- 自定义镜像可以编辑和删除
- 可以快速切换镜像的启用/禁用状态

## 外观

### 语言

- 简体中文
- English

### 主题

- **浅色** — 浅色主题
- **深色** — 深色主题
- **跟随系统** — 自动匹配系统主题
- **火山** — 火山引擎主题

## 存储

查看和管理应用数据存储位置：

| 路径 | 说明 |
|---|---|
| 应用数据目录 | 主数据存储位置（可自定义） |
| 插件目录 | 插件仓库存储（可自定义） |
| 引擎目录 | 引擎文件存储 |
| 缓存目录 | 临时缓存文件 |
| 日志目录 | 运行日志 |
| 热更新目录 | 热更新文件 |

每个路径都可以点击 **在文件管理器中打开** 快速访问。

### 自定义数据目录

可以更改应用数据的主存储位置。更改时应用会提示是否迁移现有数据。

## 其他

### 重新显示引导

重新显示首次启动时的引导向导。

### 重置数据

⚠️ 此操作将清除所有数据：

1. 项目数据
2. 插件数据
3. 引擎数据
4. 绑定关系
5. 设置

重置前需要指定备份目录，应用会自动备份数据。

## 备份与恢复

### 备份数据

1. 点击 **备份** 按钮
2. 选择备份保存目录
3. 点击 **备份** 开始

### 恢复数据

1. 在备份对话框中选择备份目录
2. 点击 **恢复**
3. 确认恢复操作（⚠️ 会覆盖当前数据）

## 团队配置

### 导出配置

1. 点击 **团队配置** → **导出**
2. 输入配置名称和描述
3. 选择要包含的项目
4. 导出包含插件绑定关系的 JSON 配置

### 导入配置

1. 选择已有的团队配置
2. 点击 **导入**
3. 应用自动创建绑定关系

团队配置适合多人协作时同步插件版本和绑定关系。

## 操作日志

点击 **查看日志** 查看最近 50 条操作记录：

- 操作类型和状态（成功/失败）
- 操作目标
- 详细信息
- 时间戳

错误日志支持一键复制详细信息。
