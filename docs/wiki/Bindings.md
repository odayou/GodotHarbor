# 插件绑定

插件绑定是将仓库中的插件版本关联到项目的过程。绑定后通过"应用变更"将插件挂载到项目的 `addons` 目录。

## 绑定流程

### 方式一：绑定管理页面

1. 进入 **插件绑定** 标签页
2. 左侧选择目标项目
3. 右侧勾选要绑定的插件
4. 选择版本、单元和挂载路径
5. 点击 **应用变更**

### 方式二：插件详情页

1. 在插件仓库中右键点击插件
2. 选择 **绑定到项目**
3. 选择目标项目和挂载路径

### 方式三：快速绑定

导入插件后，会弹出快速绑定引导：
1. 选择要绑定的项目
2. 确认挂载路径
3. 自动应用变更

## 挂载路径

挂载路径是插件在项目 `addons` 目录下的相对路径。例如：

- `my_plugin` → `res://addons/my_plugin/`
- `ui/components` → `res://addons/ui/components/`

> ⚠️ 如果两个插件挂载到相同路径，会产生冲突，状态显示为 🔀 冲突。

## 应用变更

绑定/解绑操作不会立即修改项目文件，需要点击 **应用变更** 才会执行：

1. 创建符号链接 / Junction / 复制文件到 `addons` 目录
2. 移除已解绑插件的链接/文件
3. 显示操作结果（创建数、移除数、错误数）

## 健康检查

应用会定期检查绑定健康状态：

| 状态 | 含义 | 修复方式 |
|------|------|---------|
| ✅ 健康 | 符号链接/文件正常 | 无需操作 |
| ❌ 链接失效 | 目标文件不存在 | 点击修复重新创建 |
| ⚠️ 路径冲突 | 多个绑定指向同一路径 | 解绑其中一个 |

在项目详情中点击 **修复** 可自动修复不健康的绑定。

## 批量操作

- **批量绑定** — 选择多个插件同时绑定到项目
- **批量解绑** — 选择多个绑定同时解除
- **批量应用** — 对多个项目同时应用变更

## 图形视图

绑定管理页面提供图形视图，以可视化方式展示项目与插件的绑定关系。

- 节点：项目（蓝色）和插件（绿色）
- 连线：绑定关系
- 点击节点查看详情
