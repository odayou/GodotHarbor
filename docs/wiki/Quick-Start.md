# 快速开始

## 一键设置（推荐）

首次使用时，应用启动后会自动执行：

1. 扫描配置目录中的 Godot 项目
2. 扫描项目中的插件并导入到仓库
3. 将插件自动绑定到对应项目
4. 发现本地已安装的 Godot 引擎

整个过程有进度条显示，完成后会展示结果摘要。同一设置下 24 小时内不会重复执行。

## 手动操作流程

如果偏好手动操作，可以按以下步骤进行：

### 第 1 步：添加项目

1. 进入 **项目管理** 页面
2. 点击 **扫描项目** 按钮
3. 选择包含 Godot 项目的根目录
4. 应用会自动识别所有含 `project.godot` 文件的目录

也可以点击 **添加项目** 手动选择单个项目目录，或直接将项目文件夹拖入窗口。

### 第 2 步：导入插件

1. 进入 **插件生态** 页面
2. 点击 **导入插件** 按钮
3. 选择导入方式：
   - **本地目录** — 选择插件所在文件夹
   - **Git 仓库** — 输入 Git 仓库 URL
   - **项目扫描** — 自动扫描所有项目的 addons 目录
   - **Asset Library** — 从 Godot 官方资产库搜索导入

### 第 3 步：绑定插件到项目

1. 在 **插件绑定** 标签页中
2. 左侧选择目标项目
3. 右侧勾选要绑定的插件
4. 选择版本和挂载路径
5. 点击 **应用变更**

### 第 4 步：配置引擎

1. 进入 **引擎管理** 页面
2. 点击 **发现引擎** 自动扫描本地 Godot 引擎
3. 或点击 **注册引擎** 手动指定引擎路径
4. 或点击 **下载引擎** 从官方/镜像源下载

> 💡 Godot Harbor 作为引擎的下载器和管理器，帮助你统一管理本地的 Godot 引擎。你可以用任意版本的 Godot 引擎打开任意项目——这符合 Godot 的工作方式。

## 核心概念

### 插件仓库

Godot Harbor 维护一个本地插件仓库，所有导入的插件都存储在仓库中。仓库中的插件可以被多个项目复用，无需重复安装。

### 绑定关系

绑定是"项目 ↔ 插件版本"的映射关系。一个项目可以绑定多个插件，一个插件也可以绑定到多个项目。

### 挂载策略

应用变更时，插件如何放入项目的 `addons` 目录：

| 策略 | 说明 | 推荐场景 |
|------|------|---------|
| **符号链接** | 创建符号链接指向仓库 | 日常开发（默认推荐） |
| **Junction** | Windows 目录联接 | Windows 无管理员权限时 |
| **复制** | 直接复制文件 | 需要独立副本时 |

> 💡 符号链接模式下，更新仓库中的插件后所有项目自动生效。
