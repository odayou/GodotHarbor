# Godot Harbor 用户手册

Godot Harbor 是一款为 Godot 开发者打造的桌面工具，提供统一的插件仓库、项目绑定管理和引擎环境管理。

## 核心功能

- 🔌 **插件管理** — 从本地、Git、Asset Library 导入插件，统一管理版本
- 📁 **项目管理** — 自动扫描 Godot 项目，分组管理，状态监控
- 🔗 **插件绑定** — 为项目选择插件和版本，一键挂载到 addons 目录
- ⚡ **引擎管理** — 注册、发现、下载 Godot 引擎，自动匹配项目
- 🔄 **自动更新** — 应用更新、热更新、插件更新、引擎更新
