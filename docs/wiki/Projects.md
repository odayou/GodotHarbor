# 项目管理

## 添加项目

### 自动扫描

1. 点击 **扫描项目** 按钮
2. 选择包含 Godot 项目的目录
3. 应用递归搜索所有含 `project.godot` 的目录
4. 自动识别项目名称、Godot 版本、图标

### 手动添加

- 点击 **添加项目**，选择项目目录
- 直接将项目文件夹拖入窗口

### 快速扫描

点击 **快速扫描**，使用设置中配置的扫描目录自动扫描，无需手动选择。

## 项目状态

| 状态 | 含义 |
|------|------|
| ✅ 就绪 | 项目正常，绑定健康 |
| ⚠️ 警告 | 部分绑定异常（如符号链接失效） |
| ❌ 错误 | 项目配置损坏或路径无效 |
| 🔀 冲突 | 多个插件挂载到相同路径 |
| 📂 源缺失 | 项目目录不存在 |

## 分组管理

- 右键项目 → **设置分组** 输入分组名
- 使用筛选栏按分组过滤项目
- 批量选择后可批量设置分组

## 引擎绑定

每个项目可以绑定一个 Godot 引擎：

1. 点击项目的引擎图标
2. 从已注册引擎列表中选择
3. 可选填写自定义启动参数
4. 绑定后点击 ▶ 即可启动项目

### 自动匹配引擎

应用会根据项目的 Godot 版本自动推荐匹配的引擎：
- Godot 4 项目优先匹配 Godot 4 引擎
- Godot 3 项目优先匹配 Godot 3 引擎
- 无匹配时使用默认引擎

## 项目迁移

当项目目录被移动后，应用会自动检测并提示：

1. 状态栏显示"检测到项目路径变更"
2. 点击后可选择：
   - **更新路径** — 指向新位置
   - **忽略** — 保持原路径

## 批量操作

- **批量删除** — 勾选多个项目后点击删除
- **批量设置分组** — 勾选后统一设置分组
- **在文件管理器中打开** — 打开项目所在目录
