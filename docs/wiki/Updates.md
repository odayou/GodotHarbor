# 更新中心

更新中心统一管理应用、插件和引擎的更新。

## 检查更新

点击 **检查更新** 按钮，同时检查以下更新：

- **应用更新** — Godot Harbor 自身的新版本
- **热更新** — 前端界面的增量更新（无需重新安装）
- **插件更新** — 已导入插件的新版本
- **引擎更新** — 已注册引擎的新版本

## 应用更新

### 完整更新

当检测到新版本时：

1. 查看版本号变化和更新说明
2. 点击 **更新** 下载并安装新版本
3. 安装完成后重启应用

### 跳过版本

如果不想更新到某个版本，点击 **跳过版本**。该版本不会再提醒更新。

### 手动下载

如果自动更新失败，可以点击 **手动下载** 前往 GitHub Releases 页面下载安装包。

## 热更新

热更新是前端界面的增量更新，无需重新安装整个应用：

1. 查看更新版本和大小
2. 点击 **安装热更新**
3. 进度条显示下载和安装进度
4. 安装完成后自动生效

### 回滚热更新

如果热更新导致问题，可以回滚到上一个版本：

1. 在更新页面点击 **回滚热更新**
2. 确认回滚操作
3. 应用恢复到热更新前的状态

## 插件更新

- 查看所有有新版本的插件
- 单个更新：点击插件旁的 **更新** 按钮
- 批量更新：点击 **全部更新** 按钮

## 引擎更新

引擎更新会跳转到引擎管理页面进行下载。

## 更新历史

更新历史记录所有更新操作：

- 更新类型（应用/插件/引擎/热更新）
- 版本变化
- 更新状态（成功/失败/已回滚）
- 更新时间

可以 **清除历史** 删除所有更新记录。

## 自动检查

在 **设置 → 插件仓库** 中配置：

- **自动检查应用更新** — 启动时检查新版本
- **自动检查插件更新** — 启动时检查插件更新
- **自动检查引擎更新** — 启动时检查引擎更新
- **检查间隔** — 设置自动检查的时间间隔（1-168 小时）
