# 引擎管理

Godot Harbor 作为引擎的下载器和管理器，帮助你统一管理本地的 Godot 引擎。你可以用任意版本的 Godot 引擎打开任意项目——这符合 Godot 的工作方式。

## 添加引擎

### 自动发现

1. 点击 **发现引擎** 按钮
2. 应用自动扫描系统常见路径，查找已安装的 Godot 引擎
3. 发现的引擎自动注册到引擎列表

> 💡 应用启动时也会自动运行引擎发现，无需手动操作。

### 手动注册

1. 点击 **注册引擎** 按钮
2. 输入引擎名称（可选，留空自动识别）
3. 选择引擎路径：
   - 选择引擎可执行文件所在目录
   - 或直接选择引擎可执行文件
4. 点击 **注册** 完成添加

### 在线下载

1. 点击 **下载引擎** 按钮
2. 选择下载镜像源（默认使用 Godot 官方源）
3. 使用筛选器缩小范围：
   - **通道**：Stable / RC / Beta / Alpha / Dev
   - **变体**：Standard / .NET (Mono)
   - **搜索**：按版本号搜索
   - **隐藏已安装**：过滤已安装的版本
4. 点击 **下载** 按钮，等待下载完成
5. 下载完成后引擎自动注册

## 引擎列表

引擎列表显示以下信息：

| 列 | 说明 |
|---|---|
| 名称 | 引擎名称和版本号 |
| 类型 | Godot 4 / Godot 3 / 未知 |
| 健康状态 | ✅ 正常 / ❌ 异常（可执行文件缺失） |
| 路径 | 引擎所在路径（点击可在文件管理器中打开） |

## 引擎操作

### 重命名

在更多菜单中选择 **重命名**，修改引擎显示名称。

### 删除引擎

1. 在更多菜单中选择 **删除引擎**
2. 确认删除操作
3. 可选：勾选 **同时删除引擎文件**（⚠️ 此操作不可恢复）

### 检查更新

点击 **检查更新** 按钮检测是否有新版本可用。

## 下载管理

### 下载进度

- 页面顶部显示正在进行的下载任务
- 实时显示下载进度和速度
- 可随时 **取消** 下载
- 关闭下载对话框后下载在后台继续

### 镜像源配置

在 **设置 → 引擎镜像** 中管理下载镜像源：

- 添加自定义镜像源
- 启用/禁用镜像源
- 编辑镜像源名称和 URL
- 官方源不可删除

## 搜索与筛选

- **搜索框**：按名称、版本号、路径搜索
- **类型筛选**：按 Godot 4 / Godot 3 / 未知筛选
