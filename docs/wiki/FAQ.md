# 常见问题

## 安装与启动

### 应用无法启动

- 确认操作系统版本满足要求（Windows 10+、macOS 10.15+、Ubuntu 18.04+）
- Windows 用户如遇到 SmartScreen 提示，选择"仍要运行"
- macOS 用户需要允许来自未识别开发者的应用：系统设置 → 隐私与安全性 → 仍要打开

### 首次启动很慢

首次启动时应用会自动扫描项目和发现引擎，扫描范围越大耗时越长。同一设置下 24 小时内不会重复执行。可以在设置中关闭"启动时自动扫描"。

## 项目管理

### 扫描不到项目

- 确认扫描目录设置正确（设置 → 扫描 → 扫描目录）
- 确认项目目录包含 `project.godot` 文件
- 确认应用有读取目录的权限

### 项目图标不显示

项目图标需要是 `project.godot` 中配置的 `config/icon` 指向的文件。如果图标路径无效则显示默认文件夹图标。

## 插件管理

### 导入插件失败

- **本地目录导入**：确认目录包含 `plugin.cfg` 文件
- **Git 导入**：确认网络连接正常，仓库 URL 正确
- **权限问题**：确认应用有读写目标目录的权限

### 插件绑定后项目报错

- 检查挂载策略是否正确（设置 → 挂载策略）
- Windows 用户推荐使用 **Junction** 策略
- 确认项目 `addons` 目录下有正确的链接/文件

### 符号链接创建失败

Windows 上创建符号链接需要管理员权限或开发者模式：

1. **以管理员身份运行** Godot Harbor
2. 或在 **设置 → 开发者模式** 中开启
3. 或改用 **Junction** 挂载策略（不需要管理员权限）

## 引擎管理

### 自动发现找不到引擎

自动发现会扫描以下路径：

- Windows：`C:\Program Files\`、`C:\Program Files (x86)\`、用户目录
- macOS：`/Applications/`、`~/Applications/`
- Linux：`/usr/bin/`、`/usr/local/bin/`、`~/bin/`、`~/.local/bin/`

如果引擎安装在其他位置，请使用 **手动注册**。

### 引擎下载速度慢

- 在 **设置 → 引擎镜像** 中添加国内镜像源
- 切换到速度更快的镜像源
- 也可以手动下载后使用 **注册引擎** 添加

### 引擎健康状态异常

❌ 异常表示引擎可执行文件缺失或损坏：

- 引擎可能被移动或删除
- 点击 ⚠️ 图标可快速删除异常引擎
- 重新注册或重新下载引擎

## 更新

### 热更新失败

- 检查网络连接
- 尝试 **回滚热更新** 恢复到上一版本
- 如果无法回滚，重新安装应用

### 应用更新安装失败

- 使用 **手动下载** 从 GitHub Releases 下载安装包
- 关闭杀毒软件后重试
- 确认磁盘空间充足

## 数据与存储

### 数据存储位置

默认存储位置：

- **Windows**：`%APPDATA%\com.godotharbor.app\`
- **macOS**：`~/Library/Application Support/com.godotharbor.app/`
- **Linux**：`~/.local/share/com.godotharbor.app/`

可以在 **设置 → 存储** 中查看所有路径，也可以自定义数据目录。

### 如何迁移数据

1. **设置 → 存储 → 自定义数据目录**
2. 输入新路径
3. 保存时选择 **迁移数据**
4. 等待迁移完成

### 如何备份和恢复

1. **设置 → 备份**
2. 选择备份保存目录
3. 点击 **备份** 或 **恢复**

> 恢复操作会覆盖当前数据，请谨慎操作。

## 其他

### 如何重置所有数据

1. **设置 → 其他 → 重置数据**
2. 按照向导操作
3. 重置前需要指定备份目录

### 如何切换语言

**设置 → 外观 → 语言**，选择简体中文或 English。

### 如何反馈问题

前往 [GitHub Issues](https://github.com/odayou/GodotHarbor/issues) 提交问题反馈。
