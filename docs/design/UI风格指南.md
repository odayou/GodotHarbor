# Godot Harbor UI 风格指南 v2.0

## 1. 品牌标识

### 1.1 Logo 设计规范

#### Logo 构成
- **主体**：齿轮（Gear）轮廓，象征工程与构建
- **核心**：抽象人物图形（头部圆形 + 躯干 + 展开双臂），象征开发者
- **底部**：波浪线条，象征 Harbor（港湾）的水面
- **背景**：深色圆角矩形，营造专业感

#### Logo 变体
| 变体 | 用途 | 说明 |
|------|------|------|
| 完整彩色版 | 应用图标、启动页 | 深色背景 + 蓝→青渐变齿轮 |
| 白色简化版 | 深色背景叠加 | 仅保留白色轮廓线条 |
| 单色版 | 系统托盘、水印 | 纯白色或纯灰色 |

#### Logo 安全区域
- Logo 四周保留至少 10% 的空白区域
- 最小使用尺寸：16x16px（系统托盘）
- 推荐展示尺寸：≥ 32x32px

### 1.2 品牌色彩系统

#### 核心品牌色
基于 JetBrains 风格现代蓝为核心视觉语言，以蓝→青渐变为品牌标识：

| 色彩名称 | 色值 | 用途 |
|---------|------|------|
| **品牌蓝** | `#3574F0` | 渐变起始色、主操作色 |
| **品牌辅色** | `#5A8EF4` | 渐变结束色、辅助操作色 |
| **品牌青** | `#33B5DC` | 高亮色、强调色 |
| **深蓝** | `#2B5FCC` | 深色变体 |
| **亮青** | `#6BD7EB` | 亮色变体 |

#### 品牌渐变
```
主渐变：linear-gradient(135deg, #3574F0 0%, #5A8EF4 100%)
按钮渐变：linear-gradient(135deg, #3574F0 0%, #5A8EF4 100%)
高亮渐变：linear-gradient(135deg, #3574F0 0%, #33B5DC 100%)
```

### 2.2 组件风格

#### 按钮
| 类型 | 样式 | 用途 |
|------|------|------|
| **主要按钮** | 品牌渐变背景 + 白色文字 + sm圆角 | 主操作（保存、确认） |
| **次要按钮** | 透明背景 + 品牌色边框 + 品牌色文字 | 次要操作（取消） |
| **危险按钮** | 红色背景 + 白色文字 | 危险操作（删除） |
| **幽灵按钮** | 透明背景 + 无边框 + 品牌色文字 | 辅助操作 |
| **图标按钮** | 透明背景 + 图标 | 工具栏操作 |

按钮尺寸：
| 尺寸 | 高度 | 内边距 | 字号 |
|------|------|--------|------|
| sm | 28px | 6px 12px | 12px |
| md | 36px | 8px 16px | 14px |
| lg | 44px | 10px 24px | 16px |

#### 卡片
- **背景**：surface-card
- **边框**：1px solid surface-border
- **圆角**：12px
- **阴影**：0 4px 6px -1px rgba(0,0,0,0.1)
- **悬停**：边框颜色变为品牌蓝，轻微上浮阴影
- **内边距**：20px

#### 输入框
- **背景**：surface-layer
- **边框**：1px solid surface-border
- **圆角**：6px
- **高度**：36px
- **聚焦**：边框变品牌蓝，添加 0 0 0 3px rgba(53,116,240,0.15) 阴影
- **占位符**：content-muted

#### 导航栏
- **背景**：surface-layer
- **宽度**：240px（展开）/ 64px（折叠）
- **激活项**：左侧品牌渐变边框 + 品牌色文字 + surface-hover 背景
- **图标大小**：20px
- **文字大小**：14px

#### 标签/徽章
| 类型 | 背景 | 文字 |
|------|------|------|
| 成功 | green-900/30 | green-400 |
| 警告 | yellow-900/30 | yellow-400 |
| 错误 | red-900/30 | red-400 |
| 信息 | blue-900/30 | blue-400 |
| 中性 | surface-card | content-secondary |

### 2.3 交互模式

#### 悬停效果
- 按钮：opacity 0.9 或背景变深
- 卡片：边框高亮 + 轻微阴影提升
- 列表项：背景变 surface-hover
- 过渡时间：200ms ease-in-out

#### 聚焦效果
- 蓝色外发光：0 0 0 3px rgba(53,116,240,0.15)
- 过渡时间：150ms

#### 加载状态
- 骨架屏：surface-card 背景 + 品牌渐变动画
- 进度条：品牌渐变填充
- 旋转图标：品牌色

#### 动画规范
| 动画 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 快速 | 150ms | ease | 按钮点击、颜色切换 |
| 标准 | 200ms | ease-in-out | 悬停、展开折叠 |
| 慢速 | 300ms | ease-in-out | 页面切换、模态框 |
| 弹性 | 500ms | cubic-bezier(0.34,1.56,0.64,1) | 弹出提示 |

## 3. 图标系统

### 3.1 图标风格
- **风格**：线性图标（Outlined），简洁现代
- **线条宽度**：2px（24px画布）/ 1.5px（16px画布）
- **端点风格**：stroke-linecap: butt（直角）
- **连接风格**：stroke-linejoin: miter（几何感）
- **角度**：优先 45°/90°
- **视口**：24x24（标准）/ 20x20（导航栏）
- **颜色规则**：
  - 激活状态：品牌渐变或品牌蓝

### 4.5 图标细节处理标准

#### 小尺寸（16-32px）
- 移除齿轮齿的细节，仅保留外轮廓圆和内部人物图形
- 线条加粗至3-4px等效宽度
- 简化波浪线为1-2条

#### 中尺寸（48-128px）
- 保留齿轮基本形态，减少齿数至8-10个
- 人物图形保持完整
- 波浪线保留2条

#### 大尺寸（128-512px）
- 完整展示所有细节
- 齿轮12齿
- 人物图形含头部、躯干、双臂、腿部
- 波浪线2条，带透明度层次

#### 色彩应用
- **16-32px**：使用纯色（品牌蓝 #3574F0），避免渐变在小尺寸下模糊
- **48-128px**：使用双色渐变（#3574F0 → #5A8EF4）
- **128-512px**：使用双色渐变（#3574F0 → #33B5DC）

## 5. 设计原则

1. **Islands 岛屿分层**：视觉分层 + 空间呼吸感，各功能区域如岛屿般独立而有序
2. **柔和现代**：更大圆角、柔和阴影、克制的对比度，营造舒适现代的视觉体验
3. **密度可调**：标准模式 + 紧凑模式独立于主题，适应不同使用场景
4. **一致性**：品牌渐变贯穿所有视觉元素，从Logo到按钮到图标
5. **层次分明**：通过背景色深浅和边框创建清晰的视觉层次
6. **简洁高效**：界面简洁明了，减少视觉噪音，突出核心功能
7. **专业感**：深色主题 + 精确间距 + 细腻动效，符合开发者工具定位
8. **品牌统一**：Logo、图标、UI元素共享同一套色彩系统和视觉语言
