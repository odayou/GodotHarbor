## 三、详细执行计划

### Phase 1：阻断性问题修复（本周内）

#### 1.1 MCP Server轮询优化（S6）

**问题描述**: Settings.vue中每5秒轮询一次MCP运行状态，即使页面不可见也在轮询。

**修复方案**:
1. 使用Tauri事件推送替代轮询
2. 页面不可见时暂停轮询
3. 后端添加MCP状态变更事件

**代码变更**:
- `src-tauri/src/mcp/server.rs`: 添加状态变更事件
- `src/views/Settings.vue`: 改用事件监听

**验收标准**:
- [ ] MCP状态变更时前端实时更新
- [ ] 页面不可见时不消耗资源
- [ ] 无内存泄漏

#### 1.2 CI生成集成Harbor环境同步（S8）

**问题描述**: 生成的GitHub Actions/GitLab CI配置是纯Godot构建，没有集成Harbor环境同步步骤。

**修复方案**:
1. 在CI配置中添加Harbor环境同步步骤
2. 读取.harbor.yml → 安装插件 → 构建
3. 支持harbor restore命令

**代码变更**:
- `src-tauri/src/commands/build.rs`: 修改generate_github_actions和generate_gitlab_ci
- 添加harbor restore命令或使用现有同步功能

**验收标准**:
- [ ] CI配置包含Harbor环境同步步骤
- [ ] CI中能正确安装项目依赖的插件
- [ ] 支持harbor restore命令

#### 1.3 导出模板镜像源支持（S7）

**问题描述**: Godot官方下载源在国内很慢，没有镜像选项。

**修复方案**:
1. 设置中添加导出模板下载镜像源配置
2. 支持自定义镜像URL
3. 优先使用镜像源下载

**代码变更**:
- `src-tauri/src/commands/build.rs`: download_export_template添加镜像源参数
- `src/views/Settings.vue`: 添加镜像源配置UI
- `src-tauri/src/models/mod.rs`: Settings模型添加mirror字段

**验收标准**:
- [ ] 设置中可配置镜像源URL
- [ ] 下载时优先使用镜像源
- [ ] 镜像源失败时自动回退到官方源

### Phase 2：显著问题修复（1-2周内）

#### 2.1 打开路径前检查存在性（M2）

**问题**: 打开文件管理器时可能路径不存在。

**修复方案**:
- `src/views/Build.vue`: 打开前检查路径
- `src/views/Projects.vue`: 打开前检查路径

#### 2.2 i18n key补全（M3）

**问题**: MCP Server停止按钮文案有fallback。

**修复方案**:
- 检查所有i18n key是否完整
- 补全缺失的key

#### 2.3 CI选择状态持久化（M4）

**问题**: 切换Tab后选择的项目/provider丢失。

**修复方案**:
- 使用localStorage持久化选择状态
- 或使用Pinia store

#### 2.4 预设应用确认提示（M5）

**问题**: 点击"应用预设"直接覆盖export_presets.cfg。

**修复方案**:
- 添加确认对话框
- 显示将要覆盖的内容

#### 2.5 MCP Tool增强（E1/E2）

**问题**: sync_environment和install_plugin不能自动下载。

**修复方案**:
- sync_environment: 检测缺失插件时自动从Asset Library下载
- install_plugin: 支持从Asset Library直接安装

### Phase 3：UX优化（2-4周内）

#### 3.1 菜单去重（U1）

**问题**: 右键菜单和省略号菜单100%重叠。

**修复方案**:
- 移除Projects项目卡片右键菜单
- 移除Home最近项目右键菜单
- 移除Plugins插件卡片右键菜单
- 移除Templates模板卡片右键菜单
- 保留Build页面构建记录右键菜单

**代码变更**:
- `src/views/Projects.vue`: 移除右键菜单
- `src/views/Home.vue`: 移除右键菜单
- `src/views/Plugins.vue`: 移除右键菜单
- `src/views/Templates.vue`: 移除右键菜单

#### 3.2 空状态精简（U2）

**问题**: 空状态按钮过多（11个）。

**修复方案**:
- Projects空状态: 4个按钮 → 1个"扫描项目"
- Engines空状态: 3个按钮 → 1个"发现引擎"
- Plugins空状态: 4个按钮 → 1个"导入插件"

#### 3.3 项目卡片徽章精简（U3）

**问题**: 项目卡片最多8种指示器。

**修复方案**:
- 移除插件数量指示器
- VCS Clean状态不显示
- 已锁定无漂移不显示
- 漂移和锁漂移合并为"环境变更"

#### 3.4 项目详情弹窗Tab重构（U4）

**问题**: 7个面板平铺，信息过载。

**修复方案**:
- 弹窗加宽 max-w-lg → max-w-2xl
- 分为3个Tab: 概览/环境/版本控制
- 概览Tab为默认，显示基础信息+插件+环境摘要
- 环境Tab合并漂移/锁/快照
- 锁文件和快照默认折叠

#### 3.5 模板整合到项目创建流程（U5）

**问题**: 模板是独立板块，与项目创建割裂。

**修复方案**:
- 侧边栏移除"模板"独立入口
- 项目页"添加项目"改为统一对话框
- 包含3种方式: 本地添加/Git克隆/从模板创建
- 模板管理入口移至设置页

#### 3.6 引擎缺失内联引导（U6）

**问题**: 引擎缺失时无引导。

**修复方案**:
- 选择引擎时若无引擎，显示内联引导
- 提供"发现本地引擎"和"下载引擎"按钮
