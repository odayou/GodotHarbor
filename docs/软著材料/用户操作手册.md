## 1. 概述

GodotHarbor 是一款专为 Godot 游戏引擎开发者设计的桌面项目管理工具。软件提供统一的插件仓库管理、项目绑定管理、多版本引擎管理以及团队协作配置同步等功能，帮助开发者高效管理 Godot 开发环境。

### 核心功能

- **插件管理**：从本地目录、Git 仓库或 Godot Asset Library 导入插件，统一管理版本，支持批量更新
- **项目管理**：自动扫描 Godot 项目，分组管理，实时监控项目状态
- **插件绑定**：为项目选择插件和版本，一键挂载到 addons 目录，支持符号链接、目录联接、复制三种模式
- **引擎管理**：自动发现本地引擎、在线下载安装、为项目智能匹配引擎版本
- **项目模板管理**：从 Asset Library 导入项目模板，快速创建新项目
- **团队配置同步**：导出/导入环境配置，实现团队协作环境统一
- **环境漂移检测**：自动对比项目所需环境与实际环境，及时发现配置偏差
- **更新中心**：统一管理应用更新、热更新、插件更新和引擎更新

## 3. 安装与启动

### 3.1 下载安装包

**操作步骤**：

1. 访问 GodotHarbor 发布页面（GitHub Releases 或 Gitee Releases）
2. 根据操作系统选择对应的安装包：
   - Windows：下载 `.exe` 安装包（NSIS 格式）
   - macOS：下载 `.dmg` 安装包
   - Linux：下载 `.deb` 安装包
3. 下载完成后运行安装包

**预期结果**：安装程序启动，按照向导完成安装。

### 3.2 Windows 安装

**操作步骤**：

1. 双击下载的 `.exe` 安装包
2. 如 Windows Defender 弹出"无法识别的应用"提示，点击"更多信息" → "仍要运行"
3. 按照安装向导完成安装
4. 安装完成后从开始菜单或桌面快捷方式启动

**预期结果**：GodotHarbor 成功安装并启动，显示主界面。

### 3.3 macOS 安装

**操作步骤**：

1. 双击下载的 `.dmg` 文件
2. 将 GodotHarbor 拖入 Applications 文件夹
3. 首次启动时，如提示"无法打开，因为无法验证开发者"：
   - 右键点击应用 → 选择"打开" → 点击"打开"确认
   - 或在系统设置 → 隐私与安全性 → 点击"仍要打开"
4. 启动应用

**预期结果**：GodotHarbor 成功安装并启动。

### 3.4 Linux 安装

**操作步骤**：

1. 打开终端，执行安装命令：
   ```bash
   sudo dpkg -i godot-harbor_2.2.4_amd64.deb
   ```
2. 如提示依赖缺失，执行：
   ```bash
   sudo apt-get install -f
   ```
3. 安装完成后从应用菜单启动

**预期结果**：GodotHarbor 成功安装并启动。

## 4. 首次使用引导

首次启动 GodotHarbor 时，应用会显示新手引导向导。

### 4.1 引导步骤

**操作步骤**：

1. **选择语言**：在简体中文和 English 之间选择界面语言
2. **扫描项目**：选择包含 Godot 项目的目录，应用自动识别所有含 `project.godot` 文件的项目
3. **导入插件**：应用自动扫描所有项目中的 `addons` 目录，发现并导入插件
4. **绑定插件**：将导入的插件自动绑定到对应项目
5. **了解快捷键**：查看常用键盘快捷操作说明

**预期结果**：引导完成后，项目列表显示已扫描的项目，插件仓库显示已导入的插件，绑定关系自动建立。

### 4.2 一键设置

**操作步骤**：

1. 在首页点击"一键设置"按钮
2. 应用自动执行：扫描项目 → 导入插件 → 绑定插件 → 发现引擎
3. 等待进度条完成，查看结果摘要

**预期结果**：所有项目、插件和引擎自动配置完成。同一设置下 24 小时内不会重复执行。

## 5. 项目管理

### 5.1 扫描项目

**操作步骤**：

1. 进入"项目管理"页面
2. 点击"扫描项目"按钮
3. 在弹出的目录选择器中选择包含 Godot 项目的根目录
4. 应用递归搜索所有含 `project.godot` 文件的目录
5. 自动识别项目名称、Godot 版本和项目图标

**预期结果**：项目列表中显示所有扫描到的 Godot 项目，包括项目名称、版本号和图标。

### 5.2 手动添加项目

**操作步骤**：

1. 在项目管理页面点击"添加项目"按钮
2. 在目录选择器中选择项目所在目录
3. 应用自动识别项目信息

**预期结果**：项目添加到列表中，状态显示为"就绪"。

### 5.3 拖拽添加项目

**操作步骤**：

1. 从文件管理器中拖拽项目文件夹到 GodotHarbor 窗口
2. 应用自动识别并添加项目

**预期结果**：项目添加到列表中。

### 5.4 快速扫描

**操作步骤**：

1. 点击"快速扫描"按钮
2. 应用使用设置中配置的扫描目录自动扫描

**预期结果**：在预设扫描目录中找到的 Godot 项目自动添加到列表。

### 5.5 项目状态说明

| 状态 | 含义 |
|------|------|
| ✅ 就绪 | 项目正常，绑定健康 |
| ⚠️ 警告 | 部分绑定异常（如符号链接失效） |
| ❌ 错误 | 项目配置损坏或路径无效 |
| 🔀 冲突 | 多个插件挂载到相同路径 |
| 📂 源缺失 | 项目目录不存在 |

### 5.6 分组管理

**操作步骤**：

1. 右键点击项目，选择"设置分组"
2. 输入分组名称
3. 使用筛选栏按分组过滤项目

**预期结果**：项目归入指定分组，可通过分组筛选查看。

### 5.7 批量操作

**操作步骤**：

1. 勾选多个项目
2. 选择批量操作：批量删除、批量设置分组、在文件管理器中打开

**预期结果**：批量操作应用于所有选中的项目。

## 6. 插件管理

### 6.1 资产类型

GodotHarbor 支持管理三种类型的资产：

| 类型 | 说明 | 挂载路径 |
|------|------|---------|
| 插件 (Plugin) | 包含 `plugin.cfg` 的标准 Godot 编辑器插件 | `addons/<name>` |
| 资产包 (AssetPack) | 不含 `plugin.cfg` 的资源集合（shader、材质、脚本库等） | `assets/<name>` |
| 项目模板 (Project) | 包含 `project.godot` 的完整项目 | 不挂载，作为新项目导入 |

导入时系统自动检测资产类型，无需手动选择。

### 6.2 从本地目录导入

**操作步骤**：

1. 进入"插件生态"页面
2. 点击"导入插件" → "本地目录"
3. 选择插件所在目录
4. 选择导入模式：
   - **复制到仓库**（推荐）：将插件复制到仓库，原目录不受影响
   - **纳入管理**：移动到仓库并创建符号链接回原位置
   - **仅记录索引**：不移动文件，只记录插件信息
5. 点击确认

**预期结果**：插件导入成功，在插件列表中显示。如仓库中已存在相同内容的插件，系统提示重复检测选项。

### 6.3 从 Git 仓库导入

**操作步骤**：

1. 点击"导入插件" → "Git 仓库"
2. 输入仓库 URL（如 `https://github.com/user/plugin.git`）
3. 点击确认，应用自动克隆仓库并识别插件

**预期结果**：Git 仓库克隆完成，插件导入到仓库中。

### 6.4 从项目扫描导入

**操作步骤**：

1. 点击"导入插件" → "项目扫描"
2. 应用自动扫描所有项目的 `addons` 目录
3. 列出发现的插件，选择要导入的插件
4. 点击确认

**预期结果**：选中的插件导入到仓库，系统自动为源项目创建绑定关系。内容相同的插件基于哈希去重，只保留一份。

### 6.5 从 Asset Library 导入

**操作步骤**：

1. 点击"导入插件" → "Asset Library"
2. 在搜索框中输入关键词搜索，或浏览分类列表
3. 选择需要的资产，点击"导入"
4. 系统自动检测资产类型并导入

**预期结果**：资产从 Godot 官方资产库下载并导入到本地仓库。

### 6.6 版本管理

**操作步骤**：

1. 在插件详情页查看当前版本
2. 点击版本选择器切换到不同版本
3. 可删除不需要的版本
4. 可从 Git 拉取最新代码更新版本

**预期结果**：插件版本切换成功，已绑定的项目使用所选版本。

### 6.7 插件更新

**操作步骤**：

1. 单个插件更新：右键点击插件 → "检查更新" → 点击"更新"
2. 全部插件更新：点击页面顶部的"检查更新"按钮 → 点击"全部更新"

**预期结果**：插件更新到最新版本，已绑定的项目自动使用新版本。

### 6.8 收藏插件

**操作步骤**：

1. 点击插件卡片上的 ⭐ 图标

**预期结果**：插件标记为收藏，在列表中优先显示。

### 6.9 存储管理

**操作步骤**：

1. 在插件页面底部查看存储统计信息
2. 点击"清理孤立文件"释放磁盘空间

**预期结果**：显示插件数量、版本数量、占用空间等信息。清理后孤立文件被删除，磁盘空间释放。

## 7. 插件绑定

### 7.1 绑定管理页面操作

**操作步骤**：

1. 进入"插件绑定"标签页
2. 左侧选择目标项目
3. 右侧勾选要绑定的插件
4. 选择版本、单元和挂载路径
5. 点击"应用变更"

**预期结果**：插件文件按选定策略挂载到项目的 addons 目录，绑定状态显示为"健康"。

### 7.2 从插件详情页绑定

**操作步骤**：

1. 在插件仓库中右键点击插件
2. 选择"绑定到项目"
3. 选择目标项目和挂载路径

**预期结果**：插件绑定到指定项目。

### 7.3 快速绑定

**操作步骤**：

1. 导入插件后，系统弹出快速绑定引导
2. 选择要绑定的项目
3. 确认挂载路径
4. 自动应用变更

**预期结果**：插件自动绑定到所选项目。

### 7.4 声明式配置同步（.harbor.yml）

**操作步骤**：

1. 在项目根目录创建 `.harbor.yml` 文件，定义绑定关系：
   ```yaml
   version: 1
   bindings:
     - name: my_plugin
       source: https://github.com/user/my_plugin.git
       ref: v2.1.0
       mount_path: addons/my_plugin
   ```
2. 在 GodotHarbor 中点击"同步配置"
3. 系统自动导入缺失的插件并创建绑定

**预期结果**：根据配置文件自动完成插件导入和绑定。

### 7.5 导出配置

**操作步骤**：

1. 在绑定管理页面点击"导出配置"
2. 系统将当前绑定关系写入 `.harbor.yml` 文件

**预期结果**：项目根目录生成 `.harbor.yml` 文件，可提交到版本控制系统。

### 7.6 挂载策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| Copy（默认） | 将插件文件复制到项目目录 | 通用场景，各项目独立 |
| Symlink | 创建符号链接到仓库 | 高级用户，节省磁盘空间 |
| Junction | Windows Junction 点 | Windows 下的替代链接方式 |

### 7.7 健康检查

**操作步骤**：

1. 应用定期自动检查绑定健康状态
2. 在项目详情中查看绑定状态
3. 如发现异常（链接失效、路径冲突），点击"修复"按钮

**预期结果**：异常绑定被修复，状态恢复为"健康"。

### 7.8 图形视图

**操作步骤**：

1. 在绑定管理页面切换到图形视图
2. 查看项目与插件的绑定关系可视化图

**预期结果**：以节点和连线方式展示绑定关系，蓝色节点为项目，绿色节点为插件。

## 8. 引擎管理

### 8.1 自动发现引擎

**操作步骤**：

1. 进入"引擎管理"页面
2. 点击"发现引擎"按钮
3. 应用自动扫描系统常见路径查找已安装的 Godot 引擎

**预期结果**：发现的引擎自动注册到引擎列表，显示名称、类型和健康状态。

### 8.2 手动注册引擎

**操作步骤**：

1. 点击"注册引擎"按钮
2. 输入引擎名称（可选，留空自动识别）
3. 选择引擎可执行文件所在目录或直接选择可执行文件
4. 点击"注册"

**预期结果**：引擎注册成功，在引擎列表中显示。

### 8.3 在线下载引擎

**操作步骤**：

1. 点击"下载引擎"按钮
2. 选择下载镜像源（默认使用 Godot 官方源）
3. 使用筛选器缩小范围：
   - 通道：Stable / RC / Beta / Alpha / Dev
   - 变体：Standard / .NET (Mono)
   - 搜索：按版本号搜索
   - 勾选"隐藏已安装"过滤已安装版本
4. 点击"下载"按钮
5. 等待下载完成

**预期结果**：引擎下载完成并自动注册到引擎列表。

### 8.4 引擎操作

**操作步骤**：

- **重命名**：在更多菜单中选择"重命名"，修改引擎显示名称
- **删除引擎**：在更多菜单中选择"删除引擎"，确认删除操作。可选勾选"同时删除引擎文件"
- **检查更新**：点击"检查更新"按钮检测新版本
- **一键启动**：记住上次使用的引擎，一键用正确版本打开项目

**预期结果**：相应操作成功执行。

### 8.5 镜像源配置

**操作步骤**：

1. 进入"设置" → "引擎镜像"
2. 点击"+ 添加镜像"
3. 输入镜像名称和 Base URL
4. 选择是否启用
5. 保存设置

**预期结果**：镜像源添加成功，下载引擎时可选择新添加的镜像源。

## 11. 环境漂移检测

### 11.1 自动检测

**操作步骤**：

1. 应用在以下场景自动检测环境漂移：
   - 打开项目时
   - 应用变更后
   - 引擎版本更新后
2. 系统自动对比项目所需环境与实际环境

**预期结果**：如检测到环境漂移（如项目所需引擎版本与实际绑定版本不一致、插件版本不匹配等），在项目状态中显示警告。

### 11.2 查看漂移详情

**操作步骤**：

1. 在项目列表中查看状态为"⚠️ 警告"的项目
2. 点击项目进入详情页
3. 查看"环境检测"区域的具体漂移信息

**预期结果**：显示具体的环境漂移项，包括预期配置和实际配置的差异。

### 11.3 修复漂移

**操作步骤**：

1. 根据漂移详情，选择修复方式：
   - 更新绑定到正确版本
   - 重新应用变更
   - 更新引擎版本

## 15. 常见问题（FAQ）

### Q1：应用无法启动怎么办？

- 确认操作系统版本满足要求（Windows 10+、macOS 10.15+、Linux x86_64）
- Windows 用户如遇到 SmartScreen 提示，选择"仍要运行"
- macOS 用户需要在系统设置 → 隐私与安全性中允许打开

### Q2：首次启动很慢？

首次启动时应用会自动扫描项目和发现引擎，扫描范围越大耗时越长。同一设置下 24 小时内不会重复执行。可在设置中关闭"启动时自动扫描"。

### Q3：扫描不到项目？

- 确认扫描目录设置正确（设置 → 扫描 → 扫描目录）
- 确认项目目录包含 `project.godot` 文件
- 确认应用有读取目录的权限

### Q4：导入插件失败？

- 本地目录导入：确认目录包含 `plugin.cfg` 文件
- Git 导入：确认网络连接正常，仓库 URL 正确
- 权限问题：确认应用有读写目标目录的权限

### Q5：符号链接创建失败？

Windows 上创建符号链接需要管理员权限或开发者模式。解决方案：
1. 以管理员身份运行 GodotHarbor
2. 在设置中开启开发者模式
3. 改用 Junction 挂载策略（不需要管理员权限）

### Q6：自动发现找不到引擎？

自动发现会扫描系统常见路径。如果引擎安装在其他位置，请使用"手动注册"功能指定引擎路径。

### Q7：引擎下载速度慢？

- 在设置 → 引擎镜像中添加国内镜像源
- 切换到速度更快的镜像源
- 也可手动下载后使用"注册引擎"添加

### Q8：热更新失败怎么办？

- 检查网络连接
- 尝试"回滚热更新"恢复到上一版本
- 如无法回滚，重新安装应用

### Q9：如何迁移数据？

1. 设置 → 存储 → 自定义数据目录
2. 输入新路径
3. 保存时选择"迁移数据"
4. 等待迁移完成

### Q10：如何切换语言？

设置 → 外观 → 语言，选择简体中文或 English。

### Q11：数据存储在哪里？

- Windows：`%APPDATA%\godot-harbor\`
- macOS：`~/Library/Application Support/godot-harbor/`
- Linux：`~/.config/godot-harbor/`

### Q12：如何反馈问题？

前往 GitHub Issues 或 Gitee Issues 提交问题反馈。
