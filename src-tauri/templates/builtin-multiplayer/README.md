# 多人游戏起步包

多人联机游戏起步模板，含大厅系统、聊天和玩家同步。

## 包含内容

### 网络系统
- **ENet** - 点对点网络
- 大厅系统（创建/加入房间）
- 玩家列表同步
- 断线重连

### 玩家系统
- 2D 角色控制
- 位置同步
- 玩家名称标签

### 聊天系统
- 实时聊天
- 消息历史
- 玩家颜色区分

### UI
- 大厅界面
- 玩家列表
- 聊天窗口
- 断线提示

## 目录结构

```
├── scenes/
│   ├── main.tscn           # 主场景（大厅 + 游戏）
│   ├── mp_player.tscn      # 多人玩家场景
│   └── ui/                 # UI 场景
├── scripts/
│   ├── player/             # 玩家脚本
│   ├── ui/                 # UI 脚本
│   └── autoload/           # 全局管理器
└── assets/
    ├── sprites/            # 精灵图
    └── audio/              # 音频文件
```

## 操作说明

### 大厅
- 输入 IP 地址和端口
- 点击 **Host** 创建房间
- 点击 **Join** 加入房间

### 游戏
- **WASD** - 移动
- **Tab** - 聊天
- **Esc** - 暂停

## 扩展指南

- 添加新游戏玩法：在 `scenes/game/` 创建场景
- 同步游戏状态：使用 RPC 调用
- 添加玩家属性：扩展 `player_mp.gd`
- 实现游戏逻辑：在 `network_manager.gd` 中处理

## 网络架构

- 服务器权威模式
- 玩家列表由服务器同步
- 位置使用不可靠 RPC 同步
- 游戏事件使用可靠 RPC
