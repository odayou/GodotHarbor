# Godot Harbor UI 风格指南

## 1. 品牌标识

### 1.1 Logo
- **主Logo**：基于字母G的抽象设计，代表Godot
- **颜色**：紫色到蓝色的渐变
- **变体**：
  - 彩色渐变版本
  - 白色版本（用于深色背景）
  - 圆形背景版本
  - 方形背景版本

### 1.2 品牌色彩

| 色彩名称 | 色值 | 用途 |
|---------|------|------|
| 主色1 | #6366F1 | 渐变起始色 |
| 主色2 | #3B82F6 | 渐变中间色 |
| 主色3 | #22D3EE | 渐变结束色 |
| 背景色 | #0B0F19 | 深色模式背景 |
| 文本色 | #FFFFFF | 主要文本 |
| 次要文本 | #94A3B8 | 次要文本 |

| 警告色 | #F59E0B | 警告状态 |
| 错误色 | #EF4444 | 错误状态 |

### 1.3 字体
- **主要字体**：Inter
- **字重**：
  - 标题：600-700
  - 正文：400-500
  - 小文本：400
- **字体大小**：
  - 标题1：24px
  - 标题2：20px
  - 标题3：18px
  - 正文：16px
  - 小文本：14px
  - 微型文本：12px

## 2. 界面风格

### 2.1 布局
- **布局结构**：左侧导航栏 + 顶部标题栏 + 主内容区
- **间距规范**：
  - 大间距：24px
  - 中间距：16px
  - 小间距：8px
  - 微间距：4px
- **圆角**：
  - 大圆角：12px
  - 中圆角：8px
  - 小圆角：4px

### 2.2 组件风格

#### 按钮
- **主要按钮**：渐变背景，白色文本
- **次要按钮**：透明背景，边框，彩色文本
- **禁用按钮**：灰色背景，灰色文本
- **按钮高度**：36px
- **按钮填充**：12px 24px

#### 卡片
- **背景**：#1E293B（深色模式）
- **边框**：1px solid #334155
- **圆角**：8px
- **阴影**：轻微阴影
- **悬停效果**：边框颜色变为主色

#### 输入框
- **背景**：#1E293B
- **边框**：1px solid #334155
- **聚焦**：边框变为主色，添加轻微阴影
- **文本**：#FFFFFF
- **占位符**：#64748B

#### 导航栏
- **背景**：#0B0F19
- **激活项**：左侧蓝色边框 + 主色文本
- **图标大小**：20px
- **文本大小**：14px

## 4. 应用图标

### 4.1 桌面图标
- **尺寸**：
  - 32x32px
  - 64x64px
  - 128x128px
  - 256x256px
- **格式**：.png, .ico
- **设计**：彩色渐变Logo，圆形或方形背景

### 4.2 系统托盘图标
- **尺寸**：16x16px, 32x32px
- **格式**：.png
- **设计**：简化版Logo，确保在小尺寸下清晰可见

### 4.3 移动端图标
- **尺寸**：
  - Android: 48x48px, 72x72px, 96x96px, 144x144px, 192x192px
  - iOS: 20x20px, 29x29px, 40x40px, 60x60px, 76x76px, 83.5x83.5px, 120x120px, 152x152px, 167x167px, 180x180px
- **格式**：.png
- **设计**：适应不同平台的图标规范

## 5. 设计原则

1. **一致性**：在整个应用中保持统一的设计语言
2. **简洁性**：界面简洁明了，避免不必要的元素
3. **可用性**：确保所有功能易于访问和使用
4. **视觉层次**：通过颜色、大小和位置创建清晰的视觉层次
5. **响应式**：适应不同屏幕尺寸

## 6. 实施指南

- 所有图标应使用SVG格式创建，确保可缩放性
- 颜色应使用预定义的品牌色彩
- 字体应使用Inter字体
- 组件应遵循定义的尺寸和间距规范
- 新功能应遵循现有的设计模式
